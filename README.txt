Profile Browser (Android) - APK banane ka tareeka
==================================================
A) GitHub se (bina Android Studio, sabse aasaan)
  1. github.com par free account banao -> New repository (naam: ProfileBrowser).
  2. Is poore folder ki saari files upload karo (.github folder ke saath).
  3. Repository me "Actions" tab -> "Build APK" -> Run workflow (ya push par apne aap chalega).
  4. 3-5 minute baad run khologe to neeche "Artifacts" me ProfileBrowser-apk milega. Download -> zip kholo -> app-debug.apk.
  5. Phone me APK install karo (Unknown sources allow karna padega).

B) Android Studio se
  1. Android Studio -> Open -> is folder ko select karo.
  2. Sync hone do, phir Build > Build APK(s).
  3. APK: app/build/outputs/apk/debug/app-debug.apk
